# 变更说明

## 0.1.1

文档、工具链与别名通道整理版本，无新增设备能力：

- 文档与示例中的命令统一改为标准写法 `python`（原 `py` 写法仅在需要 Windows 启动器时作为等价替换说明），macOS/Linux 的 `python3` 同样标注为等价替换
- 新增跨平台真机只读冒烟脚本 `scripts/smoke.py`：先校验 `tests/integration.json` 的 `enabled: true`，再运行集成套件；`scripts/windows-smoke.ps1` 改为共用同一份逻辑的薄包装
- 移除弃用别名：`region_pixels` / `regions_pixels` 以及"用比例数值填 `region`"的兼容通道，统一为 `region`（物理像素整数）与 `region_relative`（`0..1` 比例）；`Tunnel.from_config(executable=...)` 别名移除，改用 `iproxy`
- 新增发布元数据三处版本强制同步：`scripts/version_sync.py`（本地校验）、`tests/test_release_metadata.py`（CI 与 PR）、`scripts/verify-release-tag.py`（tag 发布校验），漏改 `pyproject.toml`、`docs/变更说明.md` 或 `docs/API使用参考.md` 任一处都会失败
- `pyproject.toml` 新增 `dev` extra（`pyflakes`、`build`）；修复 OpenCV 探测处的未使用导入告警，使文档中的 `python -m pyflakes src/uitap` 静态检查真正可用（`AGENTS.md` 安装命令更新为 `".[dev,vision]"`）

## 0.1.0 — 首个版本

首个公开版本，提供：

- 设备连接与状态探测（HTTP 9096 服务 + 日志 WebSocket）
- 截图（含比例裁剪）、控件树导出、坐标操作（点击/滑动/长按/拖拽/多段轨迹）
- 控件选择器与类 uiautomator2 的对象 API（Device/Selector/UiObject/快照查询）
- OCR 文字识别、找色/比色、本机模板匹配（Pillow，OpenCV 可选加速）、SIFT/二维码/YOLO 能力
- 工程（模块）管理：创建/上传/运行/停止/文件树/日志
- 浏览器 Inspector（本机回环监听）、USB iproxy 隧道、doctor 诊断与 init 配置
- Run 证据化执行、设备锁、i18n（中文/英文）
