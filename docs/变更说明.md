# 变更说明

## 0.1.0 — 首个版本

首个公开版本，提供：

- 设备连接与状态探测（HTTP 9096 服务 + 日志 WebSocket）
- 截图（含比例裁剪）、控件树导出、坐标操作（点击/滑动/长按/拖拽/多段轨迹）
- 控件选择器与类 uiautomator2 的对象 API（Device/Selector/UiObject/快照查询）
- OCR 文字识别、找色/比色、本机模板匹配（Pillow，OpenCV 可选加速）、SIFT/二维码/YOLO 能力
- 工程（模块）管理：创建/上传/运行/停止/文件树/日志
- 浏览器 Inspector（本机回环监听）、USB iproxy 隧道、doctor 诊断与 init 配置
- Run 证据化执行、设备锁、i18n（中文/英文）
