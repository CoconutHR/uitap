# 变更说明

## 0.1.2

缺陷修复版本：修复 0.1.1 引入的两个回归，并补齐测试与发布守卫。

- 修复 `screenshot_crop_relative()` / `save_screenshot_crop_relative()` 在 0.1.1 抛 `TypeError` 的回归（`ScreenFrame._region` 签名收窄后调用点未同步）
- 修复 `ocr_raw(region_relative=...)` 以及依赖它的 `ocr()` / `find_ocr_text()` / `wait_ocr_text()` 在传入相对区域时抛 `TypeError` 的同一回归
- 新增 `tests/test_public_api.py`（裁剪、相对坐标、图片等待、OCR 等待、设备门面与 `Selector` 构造）和 `tests/test_vision_engines.py`（强制纯 Pillow 降级路径并与 OpenCV 对齐定位结果）；单元测试 151 → 178 项
- 新增公开 API 文档覆盖与 API 面快照守卫：`scripts/api_docs_sync.py`、`tests/test_api_docs_sync.py`、`tests/api_surface.json`；公开成员必须写进 API 参考，移除成员必须提升 minor/major
- 补齐 API 参考缺项：`long_press_relative`、`assert_color_relative`、`crop_png_relative`、`element_text`、`element_scroll`、`Selector.with_attr`、`Tunnel.exit_summary`
- 真机 USB 只读验收通过（iOS 26.6.2 / 设备服务 4007），相对裁剪已纳入集成套件做端到端复验
- 示例模板目录改为 `examples/assets/`，`.gitignore` 为该目录保留例外

## 0.1.1

文档、工具链与别名通道整理版本，无新增设备能力：

- 文档与示例中的命令统一改为标准写法 `python`（原 `py` 写法仅在需要 Windows 启动器时作为等价替换说明），macOS/Linux 的 `python3` 同样标注为等价替换
- 新增跨平台真机只读冒烟脚本 `scripts/smoke.py`：先校验 `tests/integration.json` 的 `enabled: true`，再运行集成套件；`scripts/windows-smoke.ps1` 改为共用同一份逻辑的薄包装
- 移除弃用别名：`region_pixels` / `regions_pixels` 以及"用比例数值填 `region`"的兼容通道，统一为 `region`（物理像素整数）与 `region_relative`（`0..1` 比例）；`Tunnel.from_config(executable=...)` 别名移除，改用 `iproxy`
- 新增发布元数据三处版本强制同步：`scripts/version_sync.py`（本地校验）、`tests/test_release_metadata.py`（CI 与 PR）、`scripts/verify-release-tag.py`（tag 发布校验），漏改 `pyproject.toml`、`docs/变更说明.md` 或 `docs/API使用参考.md` 任一处都会失败
- `pyproject.toml` 新增 `dev` extra（`pyflakes`、`build`，Python 3.10 额外带 `tomli`），CI 安装 `".[dev,vision]"`；修复 OpenCV 探测处的未使用导入告警，使文档中的 `python -m pyflakes src/uitap` 静态检查真正可用（`AGENTS.md` 安装命令同步更新）

## 0.1.0 — 首个版本

首个公开版本，提供：

- 设备连接与状态探测（HTTP 9096 服务 + 日志 WebSocket）
- 截图（含比例裁剪）、控件树导出、坐标操作（点击/滑动/长按/拖拽/多段轨迹）
- 控件选择器与类 uiautomator2 的对象 API（Device/Selector/UiObject/快照查询）
- OCR 文字识别、找色/比色、本机模板匹配（Pillow，OpenCV 可选加速）、SIFT/二维码/YOLO 能力
- 工程（模块）管理：创建/上传/运行/停止/文件树/日志
- 浏览器 Inspector（本机回环监听）、USB iproxy 隧道、doctor 诊断与 init 配置
- Run 证据化执行、设备锁、i18n（中文/英文）
